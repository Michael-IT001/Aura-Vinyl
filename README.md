# Aura Vinyl

让专辑封面、歌词与黑胶唱盘，成为桌面的一部分。

Aura Vinyl 是一款面向 macOS 的桌面音乐氛围应用。它搭配已有音乐播放器，将动态专辑背景、同步歌词和可交互唱盘融入桌面。

## 特点

- **随专辑变化的动态背景**：从封面汲取颜色与氛围，呈现连续变化的色彩与空间层次。视觉灵感来自 Apple Music 的动态专辑背景，由 Aura Vinyl 独立实现。
- **桌面歌词**：支持同步滚动、逐字高亮和歌词翻译。逐字与翻译效果取决于歌曲及可用歌词数据。
- **封面与唱盘**：可选择专辑封面展示或唱片封面；唱盘可跟随专辑配色，也可切换经典黑胶外观。
- **音乐控制面板**：集中查看歌曲与播放进度，操作播放、暂停、切歌、音量和播放器提供的播放模式。各控制项以相应客户端实际支持的能力为准。
- **可开关的桌面交互**：启用后，按住 **Command + Option（⌘⌥）**，可浏览歌词或搓动唱盘调整播放位置，配合随操作速度变化的搓碟反馈。

## 播放器适配

适配目标为以下 **macOS 桌面客户端**，使用时需安装并正常播放相应客户端：

| 播放器 | 当前验证范围 |
|---|---|
| 网易云音乐 | 已在 Intel Mac 上重点验证；客户端更新及特殊播放场景仍可能影响适配 |
| QQ 音乐 | 已在 Intel Mac 上重点验证 |
| Apple Music | 已实现适配；真实歌曲的播放模式切换尚未完成最终验收 |
| Spotify | 已实现适配与自动化回归；尚未完成桌面客户端实机验收 |

歌词、翻译和封面的可用性取决于歌曲、数据源及网络。播放器版本和系统授权也可能影响部分控制能力。

## 安装与使用

1. 下载 DMG，打开后将 **Aura Vinyl.app** 拖入 **Applications / 应用程序**。
2. 打开 Aura Vinyl，通过菜单栏图标选择播放器和显示方式。
3. 按实际需要授予辅助功能、自动化或屏幕/系统音频录制等权限；用途以系统权限提示为准。
4. 在音乐播放器中播放歌曲，即可使用桌面封面、背景和歌词功能。

**快捷键交互默认可通过控制面板的开关管理。** 开启后：

- 按住 **⌘⌥**，将鼠标移到歌词区域，滚轮仅用于浏览，不会自动改变播放进度。
- 保持按住快捷键，点击某句歌词才会跳转到相应位置；松开快捷键会回到当前正在演唱的部分。
- 按住 **⌘⌥**，在唱盘区域拖动可搓碟、预览和调整进度；点击中心封面可切换播放/暂停。
